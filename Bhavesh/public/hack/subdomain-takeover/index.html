🛡️ Checklist 🔧 Tools — Subdomain Takeover

STEP 1 Enumerated subdomains paste karo

Recon se mile subdomains yahan copy-paste karo — ek line me ek subdomain. http:// ya https:// ho ya na ho, tool khud sahi link bana dega. List is browser me save rahegi (localStorage).

Abhi koi link nahi — upar subdomains paste karo.

STEP 2 Subdomain List Viewer

Badi list paste karo (ek line me ek URL ya subdomain) — saare links ek saath dikhenge, ek-ek karke kholo. Jis link ko khol loge wo green ✓ ho jayega, na khola hua purple rahega. Visited state isi browser me save rahegi.

Status note: exact status (200 / 404) sirf tab dikhta hai jab site CORS headers bhejti hai. Warna host respond kare to “Reachable”, aur respond na kare to “Unreachable” dikhega. “Live” matlab host ne jawab diya (200–399, koi aur HTTP status, ya Reachable). http:// links is https page se block ho sakte hain (mixed content) — wo “Unreachable” dikh sakte hain.

Abhi koi list nahi — upar URLs paste karo ya “Load example list” dabao.

Links yahi browser me save hote hain (localStorage). "Go to the link" hamesha naye tab me khulta hai.
