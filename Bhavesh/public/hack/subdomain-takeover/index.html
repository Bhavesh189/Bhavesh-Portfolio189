STEP 1 Enumerated subdomains paste karo

Recon se mile subdomains yahan copy-paste karo — ek line me ek subdomain. http:// ya https:// ho ya na ho, tool khud sahi link bana dega. List is browser me save rahegi (localStorage).

Abhi koi link nahi — upar subdomains paste karo.

STEP 2 — (baad me aayega)
Takeover check yahan aayega — Excel file milne ke baad. Tab tak sirf Step 1 (list banao + links kholo) use karo.
Links yahi browser me save hote hain (localStorage). "Go to the link" hamesha naye tab me khulta hai.
