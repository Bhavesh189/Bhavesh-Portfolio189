How to use

  1. Replace firebaseConfig in the script below with your Firebase project config.
  2. Open this file via a local server (e.g. python -m http.server 8000) and go to http://localhost:8000/panel.html.
  3. Add owners — give them email + temporary password. Share credentials with store owners.
  4. Store owners login on store-login.html (it compares SHA-256 of password with stored hash).

Security Warning: This panel has NO admin authentication. Anyone with access can add/remove owners. For production, secure hosting + server-side admin auth required.
